# docsort

CLI-инструмент, который раскладывает PDF рабочих программ дисциплин по семестрам
и даёт им понятные имена вида `Progr_Metody_Razrabotki_Resheniy_Na_Osnove_Iskusstvennogo_Intellekta_Git.pdf`.

## Зачем

После поступления в университет я скачала все учебные планы и рабочие программы —
и получила папку из десятков файлов с именами вроде `Progr_MRRnOII(GD)_ZFIbd02r_2026.pdf`.
Понять, какой файл к какой дисциплине и какому семестру относится, можно было
только открыв каждый. `docsort` делает это автоматически: читает текст PDF,
находит номера семестров и название дисциплины.

## Установка

Требуется Python 3.10+.

```bash
git clone https://github.com/<you>/docsort.git
cd docsort
python -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"     # CLI + pytest
# или: pip install -r requirements.txt
```

## Использование

### `docsort sort` — разложить по семестрам

```text
$ docsort sort --input ./pdfs --output ./sorted_by_semester
14:02:11 INFO    Найдено 4 PDF-файлов, начинаю обработку
14:02:11 INFO    1f3a9c_RPD.pdf -> семестры [1, 2]
14:02:12 ERROR   Не удалось прочитать broken.pdf: EOF marker not found
14:02:12 INFO    rpd_0457.pdf -> семестры [3]
14:02:12 WARNING annotation.pdf: упоминаний семестра не найдено -> Без_семестра
14:02:12 INFO    Готово: обработано 3 из 4. Результат в /home/me/sorted_by_semester
```

Файл, упоминающий несколько семестров, копируется в каждую папку. Исходники не изменяются.

### `docsort rename` — переименовать по названию дисциплины

```text
$ docsort rename --input ./sorted_by_semester --dry-run
14:05:40 INFO    Найдено 4 PDF-файлов. Режим: ПРОБНЫЙ ПРОГОН
14:05:40 INFO    1f3a9c_RPD.pdf -> Progr_Pri_Fiz_Kul.pdf (дисциплина: ПРИКЛАДНАЯ ФИЗИЧЕСКАЯ КУЛЬТУРА)
14:05:40 INFO    1f3a9c_RPD.pdf -> Progr_Pri_Fiz_Kul.pdf (дисциплина: ПРИКЛАДНАЯ ФИЗИЧЕСКАЯ КУЛЬТУРА)
14:05:41 INFO    rpd_0457.pdf -> Progr_Pro_Na_C++.pdf (дисциплина: Программирование на C++)
14:05:41 WARNING annotation.pdf: название дисциплины не найдено, пропускаю
14:05:41 INFO    Пробный прогон: файлы не изменены. Запустите без --dry-run, чтобы применить.
```

Схема имени: первые 3 буквы каждого слова, русские слова транслитерируются,
латинские (`Python`) не меняются, слова со спецсимволами (`C++`) остаются целиком.
При совпадении имён добавляется суффикс `_2`, `_3`, …

### `docsort rename --llm` — названия через GigaChat

Эвристика ломается, если в PDF нет стандартного заголовка или название перенесено
по строкам. С флагом `--llm` начало документа отправляется в GigaChat, который
возвращает чистое название дисциплины, которое транслитерируется целиком:
`Progr_Prikladnaya_Fizicheskaya_Kultura.pdf`. Если GigaChat недоступен или не смог
определить название, используется обычная схема.

```bash
pip install -e ".[llm]"
cp .env.example .env        # и впишите ключ в .env (файл в .gitignore)
# либо: export GIGACHAT_CREDENTIALS="<ваш ключ авторизации>"
docsort rename --input ./sorted_by_semester --llm --dry-run
```

Ключ читается из `.env` в текущей папке или из переменной окружения и нигде не сохраняется.
По умолчанию SSL-сертификат GigaChat **не проверяется**, потому что сервис использует
корневой сертификат Минцифры, которого нет в системных хранилищах. Если вы его установили,
добавьте `--verify-ssl`.

> **Приватность:** первые ~3000 символов каждого PDF уходят во внешний сервис.
> Не используйте `--llm` для документов с персональными данными.

### Общие флаги

| Флаг | Назначение |
|---|---|
| `--log-file PATH` | дублировать логи в файл |
| `-v, --verbose` | уровень DEBUG |
| `--version` | версия |

Флаги ставятся до подкоманды: `docsort --log-file run.log sort -i pdfs -o out`.

## Тесты

```bash
pytest
pytest --cov=docsort --cov-report=term-missing
```

Тесты не требуют реальных PDF: логика поиска проверяется на текстовых строках,
а `pypdf` подменяется моками.

## Структура

```text
docsort/
├── cli.py         # argparse, подкоманды, настройка логирования
├── extractor.py   # извлечение текста из PDF
├── semester.py    # поиск семестров + команда sort
├── discipline.py  # название дисциплины, транслитерация + команда rename
└── utils.py       # unique_path
```

## Почему argparse, а не click

Инструмент маленький: две подкоманды и несколько флагов. `argparse` входит в
стандартную библиотеку, не добавляет зависимостей и полностью покрывает задачу.
Click стоит брать, когда команд много, нужны составные группы, интерактивные
подсказки или удобное тестирование через `CliRunner` — здесь это избыточно.

## Ограничения

- Нужен текстовый слой в PDF. Сканы без OCR дадут пустой текст
  (можно предварительно прогнать через `ocrmypdf`).
- Шаблоны рассчитаны на типовые рабочие программы российских вузов: маркер
  «РАБОЧАЯ ПРОГРАММА ДИСЦИПЛИНЫ» и подсказка «(наименование дисциплины)».
- Номера семестров ограничены 1–8 (бакалавриат). Регулярные выражения могут
  ловить ложные совпадения, например в таблицах трудоёмкости.
- `sort` не рекурсивен и перезаписывает одноимённые файлы в целевых папках
  при повторном запуске.
